Quick guide

How to use this map

1. Find a record

Use the search box for a name, place, source, date, or record ID. Unmapped records remain searchable.

2. Choose locations

Select Both, Origins, Captivity, or No Location Data. The last option keeps the map visible without markers and lists records with neither a documented origin nor a documented captivity location.

3. Narrow the dates

Move the two year controls to focus on a historical period.

4. Read the evidence

Click a marker to narrow the list, then select a name to open its concise historical record.

Remember: connection lines indicate documented associations, not reconstructed travel routes. Unknown locations are never placed at an artificial point.

Interpretive caution: markers represent documented associations with places. Lines connect a recorded origin and captivity location; they do not reconstruct a journey or route. Concentrations reflect the surviving documentary sample.

Every source row remains searchable. Records with unknown locations appear in the list without an invented marker. The basemap is © OpenStreetMap contributors and requires no API key.
