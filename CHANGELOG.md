# Changelog

## Version 1.2 — 2026-11-25

- Turned documented connections on by default, including after Reset Filters.
- Made both time-slider handles use the same color and full opacity.
- Reordered the map options to Both, Origins, Captivity, and No Location Data.
- Added a searchable No Location Data view that keeps the marker-free map visible.
- Removed only the `Mediterranean Captivity Project · Version 1.1` heading.
- Moved the normalized-year/January 1 explanation beneath Date in historical records.
- Revised historical records to nine fields in the agreed order.
- Separated Source and Notes using their original CSV columns and added Ship Name.
- Preserved the Version 1.1 layout, styling, navigation, OpenStreetMap basemap, search, date filtering, corrections, guide, reset control, and single complete CSV download.

## Version 1.1 — 2026-11-25

- Preserved the Version 1 layout, colors, typography, sidebar, map legend, record list, and slide-out record panel.
- Removed CARTO and switched to an OpenStreetMap basemap requiring no API key.
- Added a concise how-to guide.
- Added explicit Both, Captivity, and Origins filters.
- Added Reset Filters.
- Simplified historical entries to eight fields.
- Kept all 3,137 records searchable, including records without map coordinates.
- Provided one complete CSV download.
- Removed 812 Strait of Gibraltar placeholder positions while retaining those records.
